상속 금융비서 가이드
상속 금융조회 문서를 인식하고, 금융정보를 구조화·정규화한 뒤 규칙 기반 이상치 검증, 사용자 수정, 우선순위 산정, 업무 관리 및 근거 기반 AI 상담까지 연결하는 Streamlit MVP입니다.

권장 시연 순서
① PDF로 RapidOCR 작동 확인 → ② 검토된 TXT 파일 불러오기 → ③ LLM 정보 추출 및 후속 기능 실행

1. 실행 환경
Windows 10/11
Python 3.11 권장
인터넷 연결
OpenAI API 키
OCR 실행에는 필요하지 않습니다.
LLM 정보 추출과 RAG 기반 AI 상담에는 필요합니다.
2. 최초 설치 및 실행
프로젝트 폴더에서 명령 프롬프트를 열고 다음 명령을 순서대로 실행합니다.

py -3.11 -m venv .venv
call .venv\Scripts\activate.bat
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
브라우저가 자동으로 열리지 않으면 터미널에 표시되는 로컬 주소를 브라우저에 입력합니다.

재실행할 때는 다음 명령만 사용합니다.

call .venv\Scripts\activate.bat
streamlit run app.py
3. 심사위원용 권장 데모 진행 순서

test.pdf

하단의 OCR 텍스트 확인 및 수정 영역에서 추출된 텍스트를 확인합니다.
PDF 단계의 목적
이 단계는 PDF 문서가 이미지로 변환되고 RapidOCR를 통해 텍스트가 추출되는지 확인하기 위한 OCR 기능 시연입니다.

현재 데모의 RapidOCR는 표 구조, 기관명, 숫자, 날짜 등에서 인식 품질 편차가 발생할 수 있습니다. 따라서 PDF에서 추출된 OCR 결과를 그대로 후속 LLM 처리에 사용하지 않고, 다음 단계에서 OCR 내용을 검토·정리한 별도의 TXT 파일을 사용합니다.

STEP 2. 검토된 TXT 파일 불러오기
OCR 시연이 끝난 뒤, 후속 AI 파이프라인은 검토된 TXT 파일을 기준으로 진행합니다.

파일 업로드 영역에서 기존 PDF 대신 다음 파일을 선택합니다.
가상_상속인_금융거래_조회결과_텍스트추출본.txt
TXT 파일 직접 불러오기 버튼을 클릭합니다.
OCR 텍스트 확인 및 수정 영역에 가상 금융조회 문서의 전체 내용이 표시되는지 확인합니다.
기관명, 금액, 날짜, 금융항목 등이 정상적으로 표시되는지 확인합니다.
TXT 파일을 사용하는 이유
현재 MVP에서는 OCR 성능과 후속 AI 처리 성능을 분리해 검증하기 위해 다음과 같이 구성했습니다.

현재 MVP
PDF 업로드 → RapidOCR 작동 확인 → 검토된 TXT 입력 → LLM 구조화

실서비스 확장
금융문서 업로드 → 금융문서 특화 OCR·레이아웃 분석
→ 구조화 정보 추출 자동 연계 → 저신뢰 필드만 선택 검토
즉, TXT 파일은 새로운 데이터를 임의로 만든 것이 아니라 가상 금융조회 문서에서 추출해야 할 내용을 검토 가능한 텍스트 형태로 정리한 후속 처리용 입력 파일입니다.

STEP 3. OpenAI API 키 입력
왼쪽 사이드바의 OpenAI API 키 입력창에 심사위원 본인의 API 키를 입력합니다.
생성 모델은 기본값인 다음 모델을 사용할 수 있습니다.
gpt-4.1-mini
입력한 계정에서 기본 모델을 사용할 수 없는 경우, 사용 가능한 모델명으로 변경합니다.
API 키는 비밀번호 형식으로 표시됩니다. 제출본에는 팀 개인 API 키를 포함하지 않아야 합니다.

6. 주의사항
본 서비스는 법률·세무 판단이나 상속 승인·포기·한정승인을 자동으로 결정하지 않습니다.
우선순위는 법률적 위험도를 확정하는 점수가 아니라, 사용자가 먼저 확인할 금융업무를 정렬하기 위한 안내 점수입니다.
현재 OCR는 기술 작동 확인용이며, 후속 AI 단계는 검토된 TXT 입력을 기준으로 진행합니다.
실서비스에서는 금융문서 특화 OCR·표·레이아웃 분석 모델을 적용하여 별도 TXT 입력 없이 후속 단계로 자동 연계하고, 저신뢰 필드만 선택적으로 검토하는 방식으로 확장할 수 있습니다.
실제 서비스 적용 시 본인인증, 상속관계 검증, 개인정보 보호, 암호화 저장, 감사 로그 및 금융기관 시스템 연계가 추가로 필요합니다.
